# C3 local sender/fetch slice, 2026-11-09

Status: **partial package, tested slice** on `ai/c3-rest`, base `e9aee56`.

## Source and changes

The base already contains `origin/agent/c3`. Ported the six C3-only commits
`3e2ef9e`, `9d64f53`, `19c9673`, `f5083d0`, `286c422`, `8d62dcf` from
`origin/agent/c3-2`; no unrelated commits were merged. This brings the info
API client, sender, refresh loop, encrypted-record cache and name/topic UI,
and limits server channel creation to owners/admins.

Additional fixes and regression tests:

- An unqueued key request or answer can retry immediately; overlapping
  answer passes share one send.
- All 500 channels are queried in batches within the server's 200-ID bound.
- A slow cache read cannot replace a newer displayed edit. Cached keys must
  belong to the subject's current owning conversation.
- Upload results and sends stop when their session ends. Reauthentication
  recreates the API adapter with the rotated token.
- Real native MLS send/receive covers all three info payloads: hidden,
  unfranked, no report reveal, and persisted on sender and receiver.
