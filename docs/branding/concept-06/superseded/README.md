# Superseded brand assets

These are the **old Indigo→Sky brand on an Ink ground**, kept as a record. The
app dropped that palette for K2 · Bone on 2026-08-07 — see
[`../../../design.md`](../../../design.md) §K.

**Do not export or reference anything in this directory.** The live family is
one level up, and every file there is on the Bone palette.

| File | Was |
| --- | --- |
| `veritra-app-icon.svg` | Mark on an Ink squircle. Replaced by `../veritra-app-icon-bone.svg`. |
| `veritra-mark-white.svg` | Pure `#FFFFFF` knockout. Replaced by `../veritra-mark-bone.svg` — the direction's on-dark accent is the warm `#EDE4DA`, not white. |
| `veritra-app-icon-{1024,512}.png` | Rasters of the Ink icon. Replaced by `../exports/veritra-app-icon-bone-{1024,512}.png`. |

The gradient versions of the mark, wordmarks and favicon are not duplicated
here; they are recoverable from git history at `194bd0c`, and the wider
exploration round they came from is still in [`../..`](../../README.md).
