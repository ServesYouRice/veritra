<claim>
IDs interpolated unencoded into authenticated request paths allow dot-segment and query injection (medium)

Many methods interpolate IDs straight into the path string without encoding. These include revokeDevice, revokeInvite, listChannels, createChannel, addConversationMember, updateRetention, listMessages, listMessagePage, sendReaction, markRead, markReadPrivate, listReceipts, sendTyping, disablePush, deviceLink, approveDeviceLink and completeDeviceLinkClaim. _jsonRequest then calls Uri.parse(baseUrl).resolve(path), which removes dot segments. An ID such as '../account' therefore turns revokeDevice into DELETE /api/v1/account, sent with the user's bearer token. IDs containing '?' or '#' change the query or fragment. Other methods in the same file encode correctly with Uri.encodeComponent, so the treatment is inconsistent.
</claim>
