Backup export can combine incompatible database revisions (high)

SecureLocalStore.exportBackup reads related state through separate awaited operations without a shared transaction or synchronization. A sync commit between the crypto-state and cursor reads can produce a backup containing pre-event MLS state but a post-event cursor. Outgoing commits can similarly introduce outbox entries whose matching crypto-state update is absent. Production exposure depends on whether unavailable callers quiesce all writers.
</claim>
