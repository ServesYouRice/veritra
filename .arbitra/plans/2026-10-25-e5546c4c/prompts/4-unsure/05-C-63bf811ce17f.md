<claim>
Owner bootstrap is authorized by loopback client IP when no setup token is configured (high)

When SetupToken is empty, setupAuthorized grants owner enrollment (reserveOwnerEnrollment and createOwner) to any request whose a.clientIP(r) parses as a loopback address. A loopback source does not prove that a local operator is present. Behind a same-host reverse proxy that forwards to 127.0.0.1, every remote request arrives from loopback. If clientIP derives the address from forwarding headers without strict trusted-proxy handling, a remote client can supply 127.0.0.1 itself. clientIP is not in the snapshot, so which case applies is unverified.
</claim>

</what_the_verifier_said>
