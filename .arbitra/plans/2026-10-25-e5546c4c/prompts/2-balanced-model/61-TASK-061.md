<goal>

This matters because it fixes:
- In-flight plaintext notifications are not invalidated on detach or session change (medium)
  <quotes> void detach() { if (state.onMessagesPublished == _onPublished) { state.onMessagesPublished = null; } } </quotes> <quotes> await _setup(); final notification = LocalNotification(title: title, body: body); notification.onClick = onClick; await notification.show(); </quotes> handle captures the session and plaintext candidates before asynchronous window and mute checks, but never verifies that the same session is still active before displaying them. detach only prevents future callbacks; it does not invalidate work already running.
