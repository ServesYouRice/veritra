<goal>
Ensure the POST /api/v1/auth/logout revocation is sent on an HTTP client that has not been closed, while keeping local sign-out first in AppState.logout and AppState.relinkAfterSyncRecovery in mobile/lib/core/app_state.dart.

This matters because it fixes:
- Logout closes the client before requesting token revocation (high)
  logout() captures the active client, but _clearLocalSession() closes that client before the remote logout request. If close() closes the request transport, revocation fails even online and its exception is silently swallowed. relinkAfterSyncRecovery() repeats this ordering.
