<goal>
Change APNsProvider.SendEncryptedEventAvailable in server/internal/push/native.go to parse the JSON reason field instead of searching the body for substrings. Return ErrSubscriptionGone only for HTTP 410 or reason Unregistered. Following the section-dc6acc39e79b6ef9aaada424/Q-002 recommendation, return BadDeviceToken as a non-gone error so that an environment mismatch no longer retires valid subscriptions.

This matters because it fixes:
- APNs BadDeviceToken is treated as a permanently gone subscription, though it is also returned for a sandbox/production environment mismatch (medium)
  APNsProvider picks a single APNs environment from the process-wide Sandbox flag. It then maps any response body containing the substring "BadDeviceToken" to ErrSubscriptionGone. Apple returns BadDeviceToken (HTTP 400) for malformed tokens and also when a valid token is sent to the wrong environment. A development-build token sent to production, or a production token sent to sandbox, is therefore reported as permanently invalid. The match is a raw substring search, not an exact parse of the JSON `reason` field.
</goal>
